# PesebreNavidad – Proyecto Interactivo Universitario

## 📌 Descripción del proyecto

**PesebreNavidad** es un proyecto web interactivo desarrollado en el contexto académico universitario, cuyo objetivo principal es ofrecer una experiencia visual e interactiva relacionada con el pesebre navideño.

El proyecto se encuentra actualmente **desplegado y funcionando en una máquina virtual dentro de las instalaciones de la universidad**, permitiendo que los estudiantes puedan acceder, visualizar e interactuar con la aplicación de forma directa.

Además, este proyecto ha sido concebido como una **base de aprendizaje colaborativo**, de modo que, con el tiempo, los estudiantes de la carrera de Computación podrán añadir mejoras, nuevas funcionalidades y optimizaciones tanto a nivel visual como funcional.

## ⚙️ Despliegue y ejecución

### Requisitos
- Java JDK 8 o superior.
- IDE compatible (Eclipse, IntelliJ IDEA).
- Servidor de aplicaciones (Apache Tomcat u otro compatible).
- Máquina virtual configurada dentro de la red universitaria.

### Pasos generales
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/NicoleParedes24/PesebreNavidad.git
   ```

2. Importar el proyecto en el IDE como proyecto existente.
3. Configurar el servidor de aplicaciones.
4. Ejecutar y verificar el correcto funcionamiento.
